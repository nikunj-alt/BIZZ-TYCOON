About

What is GASTECT?

GASTECT is a smart safety alarm for homes and small businesses. It combines an Arduino Uno with gas, flame, motion, and ambient-light sensors to detect hazards early — then alerts you with colors, tones, and a live dashboard you can read at a glance.

Capabilities

Engineered for reliability

Every layer built to respond in real time and survive poor conditions.

10 integrated sensors

Gas (MQ2), flame, PIR motion, LDR light, touch, joystick, buzzer, servo valve, battery monitor, and system status.

Real-time pipeline

Arduino C++ → HC-05 Bluetooth → Python WebSocket bridge → Next.js dashboard, with sub-100ms latency.

Immersive 3D visuals

Three.js + React Three Fiber particle systems, morphing geometry, and status-reactive lighting.

Three-tier alerting

SAFE · WARNING · DANGER with distinct colors, tones, and one-tap evacuation.

End-to-end data

Firmware → Bluetooth serial → Python bridge → SQLite history → dashboard.

Local-first

Zero cloud dependency for competition reliability — runs entirely on localhost. Data never leaves your network.

How it works

From sensor to screen

01

Hardware

Arduino Uno reads the sensors and runs the actuator logic.

02

Communication

HC-05 Bluetooth / serial streams JSON telemetry at 1 Hz.

03

Bridge

Python WebSocket server parses, classifies, and logs readings.

04

Dashboard

Next.js renders live 3D visuals, charts, and controls.
